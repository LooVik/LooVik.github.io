Enemy Escape

Unreal Engine 4 escape level — outrun an enemy through arenas, platforming, and a bridge finish.

What is this project?

Enemy Escape is a solo university level-design project from 2022, built in Unreal Engine 4. The player has to escape a pursuing enemy through a timed run — sprinting across open arenas, crossing vertical platforming sections, and reaching a bridge where they can pick up objects to help get away. I laid out the full escape route, blockout, and dressing (stone walls, wooden structures, gates, and chase pacing through each zone).
