HeroGen 2

勇者大人的刷怪城 remaster — pixel-art mobile RPG rebuilt at Itchi Technology with expanded systems, cleaner UI, and a modern live-ops foundation.

Ongoing project. This page tracks development progress and will be updated as more systems ship. Dungeon combat (sections 5–8) is on a separate implementation track and is not part of my completed scope below.

Role: Unity developer

Studio: Itchi Technology Limited

Platform: iOS & Android (mobile portrait)

Original release: HeroGen (v1) on the App Store

Technology: Unity, C#, Addressables / AssetBundles, JSON save sync, remote config, mobile UI

What is this project?

HeroGen 2 is a full remaster of the studio’s existing Hong Kong–developed pixel RPG. The first version shipped with auto-battle dungeon farming, equipment synthesis, decoration placement, lucky draws, weekly rankings, and reincarnation loops. This rebuild keeps the core identity but targets a stronger UI, clearer progression, more live-event support, and a cleaner codebase for long-term updates.
