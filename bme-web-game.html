What is this project?

Kick-Start Crew is a browser-based multiplayer serious-game platform developed for The Hong Kong Polytechnic University Department of Biomedical Engineering. Players join rooms from a lobby and progress through three connected games — a drawing activity, a cooperative 2D elder-care simulation (Game 2: ElderCare Quest), and a 3D building experience — designed as a team-building and training tool.

What I contributed

Shared multiplayer foundation, lobby, and game flow

  • Built the initial multiplayer Lobby UI with room joining and live player-list updates.
  • Implemented Socket.IO room connection and event handling — join success, player joins/departures, socket IDs, room state, and master-client identification.
  • Implemented master-client scene control so only the master initiates scene changes while every player in the room transitions together.
  • Added reusable game-action sending and receiving to synchronize gameplay events between clients.
  • Added lobby progression rules — admin-room behaviour and locking/unlocking Game 2 and Game 3 based on completion of preceding games.

Game 1 — Drawing

  • Implemented mouse-cursor synchronization so players see each other's drawing activity in real time.
  • Built an early voting flow and drawing UI integration with Socket.IO game-action handling.
  • Added server tracking, score synchronization, results flow, topic display, and end-panel layout fixes.

Game 2 — 2D ElderCare Quest

  • Built the 2D top-down gameplay foundation — grid movement, character selection, animation, collision, camera follow, spawn points, and player labels.
  • Developed the room editor for placing, moving, validating, deleting, saving, and regenerating furniture and NPCs using CSV and JSON data.
  • Implemented interactive furniture and NPC quest systems — food, water, medicine, bathing, toilet assistance, bed tidying, and desk tidying.
  • Built cooperative quest mechanics requiring multiple players — interaction zones, timed progress, player-count validation, completion states, and score awards.
  • Implemented NPC behaviour — random quest assignment, follow-player, return-to-origin, quest abandonment, task reset timers, and recovery when a player disconnects.
  • Integrated real-time multiplayer states — player actions, quest interactions, score updates, movement, reconnect/disconnect handling, and synchronized UI labels.
  • Added gameplay analytics and result reporting — movement steps, completed quests, team score, contribution percentage, and server submission.
  • Created in-game UI for interaction prompts, held-item indicators, quest markers, progress bars, score panels, and end-of-game summaries.
  • Diagnosed and fixed multiplayer edge cases — stuck players, overlapping interactions, spawn positions, NPC state, furniture collisions, and score sync.

Game 3 — platform integration

  • Implemented lobby progression logic controlling when the Game 3 button becomes available.
  • Contributed to the shared Socket.IO, lobby, master-client, and synchronized scene-transition foundations used to enter and coordinate multiplayer games across the platform.
